[![Get the plugin](https://img.shields.io/badge/Get_the-companion_plugin-9fd3ff)](https://github.com/abdullahhasan42/hollow-knight-and-silksong-plugin)

A dark, ornate Obsidian theme inspired by the two kingdoms of Hollow Knight and Silksong. **Hallownest** is void black, pale bone and blue soul light. **Pharloom** is dark lacquer, crimson silk and bell gold. Switch between them in one click.

## Install

**From Obsidian** (recommended):
1. Open **Settings, Appearance**, then select **Manage** next to Themes.
2. Search for **Hollow Knight and Silksong**, then select **Install and use**.
3. Install and enable **Style Settings** from **Settings, Community plugins, Browse**. It holds the kingdom switch and every option.
4. Optional: install **Hollow Knight and Silksong Companion** from Community plugins for the title screen, area cards, HUD and bench.

**By hand:**
1. Download `theme.css` and `manifest.json` from the [latest release](https://github.com/abdullahhasan42/hollow-knight-and-silksong-theme/releases/latest).
2. Put them in `<your vault>/.obsidian/themes/Hollow Knight and Silksong/`.
3. Open **Settings, Appearance** and pick **Hollow Knight and Silksong**.

**Snippets:** copy the files in `snippets/` into `<your vault>/.obsidian/snippets/` and turn them on under **Settings, Appearance, CSS snippets**.

## Performance

The theme is built to stay light on the GPU. The fog is static by default; **Fog drift** animates it, which redraws the whole window every frame. **Low power** turns off drift and idle animations and slows the plugin's particles. With the plugin, all motion pauses while Obsidian is in the background. The theme also follows your system's reduced motion setting.

## Privacy

The theme makes no network requests. Every font, icon and ornament is embedded in `theme.css`, so it works fully offline.

## Fonts and license

If Trajan Pro or Perpetua is installed on your computer, the theme uses it first. Otherwise it uses the embedded fonts: Cinzel and Cinzel Decorative for titles, Cormorant Garamond for note text. All three are under the SIL Open Font License; the texts are in `fonts/`.
